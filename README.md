# 48H Iron Kart

Site officiel des 48H Iron Kart, course de karting d'endurance de 48 heures au Circuit du Roussillon (édition 2027).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # build de production
```

Déployé sur Vercel à chaque push sur `main`. Variable d'environnement : `NEXT_PUBLIC_SITE_URL` (adresse définitive du site).

Réalisation : Propulsif.
